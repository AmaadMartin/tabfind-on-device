TabFind harness

The same panel, pipeline and ADK agents the extension runs, against a fixed synthetic set of 40 tabs. No extension install required, which makes the whole thing scriptable.

Why these queries

The first four share no words with the title of the tab they should find. ctrl-F cannot answer them by construction, so they isolate whether retrieval is actually semantic.

  • that thing about the refund → “Order #48213 - Return authorization”
  • the flight thing → “Itinerary confirmation - LHR to SFO”
  • what do I need to sign → “DocuSign - Awaiting your signature”
  • the doctor thing → “Lab results are ready to view”

Reading the trace

Each search prints its pipeline stages with timings: query expansion, then the deterministic BM25 prefilter (how many tabs survived), then one schema-constrained scoring call per surviving candidate.
